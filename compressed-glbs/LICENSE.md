# Vehicle model licenses

The GLB files in this folder are **not the original models**. Each is a modified version of
the Sketchfab model credited below: simplified (fewer triangles), edited, and compressed
(meshopt geometry, WebP textures). The Cybercab was generated from two models. The app
modifies them again when it loads them (see the README's "Vehicle models").

Each file is shared under the same license as its original. The MIT license of this
repository does not apply to them.
