Guide: what each setting does

Every setting in the Lab's Parameters panel, grouped the same way, with the value the real stunt uses and what changing it does. The Tweak it card changes the five with the biggest effect; the Lab has all of them, and every one can also go in the page's URL (e.g. /?apexHeight=9). See it fly opens the simulation with the setting flown lower and higher beside the real stunt, as colored cars.
